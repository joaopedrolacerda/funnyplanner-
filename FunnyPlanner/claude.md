# AppMixer — App/

App de planner poker, com o objetivo de facilitar as plannings dos usuários, o usuário podera criar uma unica sala, essa sala vai liberar um link http liberando apenas uma rota para que outras pessoas acessem essa sala(via navegador) assim que acessarem, vão poder digitar seu nome de usuário(não fica salvo, só corresponde a sessão inicial) assim que a sala foi finalizada o link interno deve voltar a ficar bloqueado

## Fluxo de trabalho

- Toda função nova deve ganhar um teste (`funnyPlannerTest/`, framework **Testing**).
- Respeitar a camada de cada arquivo (model ≠ view ≠ helper).
- Tipos em **PascalCase**, propriedades/métodos em **camelCase**.
- Preferir `async/await` a Combine.
- Pedir permissão antes de uma mudança brusca (mover arquivos, refatorar camada,
  mexer no motor de áudio).
- Build/test pelo Xcode (`BuildProject` / `RunAllTests`).
